# My Portfolio Website

This is a modern, classy, recruiter-friendly portfolio website built with React and Vite. It showcases resume details, projects, skills, achievements, testimonials, a blog, and contact information. The site is designed for easy deployment to Vercel or Netlify.

## Features
- Resume section with downloadable PDF
- Projects showcase
- Advanced tech stack
- Achievements and testimonials
- Blog section
- Contact form
- Responsive and accessible design

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Deployment
- Deploy easily to Vercel or Netlify by connecting your repository and following their instructions.

## Customization
- Update content in the `src` folder to personalize your portfolio.
